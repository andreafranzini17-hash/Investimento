Se appare un errore di autorizzazione, pubblica le regole contenute in FIRESTORE_RULES.txt nella console Firebase > Firestore Database > Regole.

2. Verifica che lo stato diventi “sincronizzato”.
3. Telefono: stesso URL e stesso account Google. Attendi qualche secondo o riapri la pagina.
4. Se compare un errore, comunica il testo esatto.
